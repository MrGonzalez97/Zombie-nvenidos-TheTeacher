🧟 Instalar Zombie-nvenidos

La misma aplicación funciona en Android, iPhone y computadora. Una vez publicada en HTTPS, podés instalarla con un ícono en la pantalla de inicio. El cooperativo necesita Internet.

🤖 Android (Chrome)

Si no aparece la instalación directa, abrí el menú ⋮ de Chrome y elegí Instalar aplicación o Agregar a pantalla de inicio.

🍎 iPhone (Safari)

  1. Abrí esta página en Safari (no desde el navegador interno de WhatsApp o Instagram).
  2. Tocá el botón Compartir (cuadrado con flecha).
  3. Elegí Agregar a pantalla de inicio y activá «Abrir como app» si aparece.
  4. Tocá Agregar. El ícono aparecerá junto a tus aplicaciones.
En iPhone no se instala un APK. Esta es una aplicación web instalable, no un archivo .ipa firmado.

🎮 Cooperativo

Entrá desde la aplicación instalada. El anfitrión selecciona «Cooperativo online» y «Crear partida». Sus amistades ingresan el código de sala. Si el anfitrión sale, la sala se cierra.

Guardados: el anfitrión puede exportar una copia JSON e importarla posteriormente desde el menú cooperativo del juego. No borres los datos del sitio si no exportaste antes tu partida.

Abrir Zombie-nvenidos

Instalación y caché offline requieren HTTPS o localhost. La experiencia offline solo está garantizada en modo individual después de cargar el juego una vez; online requiere conexión y servidor activo.
